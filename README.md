# Каталог Продуктов и Категорий
## Описание
Проект реализует каталог товаров и категорий, демонстрируя основы объектно-ориентированного программирования (ООП) на примере организации онлайн-магазина. Главная цель проекта — показать возможности структурирования и управления данными средствами Python с применением принципов OOP, таких как наследование, композиция и инкапсуляция.

## Структура проекта
- src/: директория с основными исходниками программы.
- tests/: директория с модульными тестами для проверки функциональности.
- data/: каталог с ресурсами (например, JSON-данные).
## Особенности проекта
### Основные концепции и архитектура:

- Проект организован с использованием классов и наследования. 
- Реализована простая система классификации товаров с возможностью фильтрации по категориям.
- Применены механизмы множественного наследования и миксинов для расширения функциональности.
- Разработаны абстрактные классы и классы-наследники для лучшей масштабируемости и модификации кода.

### Управление товарами и категориями:

- Товары представлены двумя основными типами: смартфонами и газонной травой.
- Поддерживаются разнообразные операции с объектами: добавление, удаление, расчет суммарной стоимости и прочего.
- Возможность добавления товара в определенную категорию и управление этими категориями.
### Механизм тестирования:

- Модульные тесты покрывают большинство ключевых функций и обеспечивают стабильную работу приложения.
- Автоматическое тестирование охватывает базовые сценарии использования, обеспечивая высокое покрытие кода.

```

Для проверки качества кода и надежности функционирования выполните модульные тесты:

```
## Принцип работы
### Классы и их роль:
 - BaseProduct: Абстрактный класс, определяющий общую структуру для всех продуктов.
 - Product: Родительский класс для реальных продуктов, обеспечивающий основную функциональность.
 - Smartphone/LawnGrass: Конкретные классы товаров, обладающие уникальной информацией.
 - Category: Класс для категоризации товаров, позволяющий группировать и получать статистику по продуктам.
### Реализации и методы:
- Вся информация о продуктах хранится централизованно, гарантируя согласованность данных.
- Цены защищены от введения некорректных значений, а сами товары классифицируются по категориям.
- Система поддерживает интуитивное представление данных через методы __str__ и __repr__.
## Примеры использования
### Пример создания товара и работы с ним:
```python

from src.models import Product, Category

# Создаем товар
apple_iphone = Product("Apple iPhone 15", "Новый айфон с продвинутым дизайном", 120000, 10)

# Создаем категорию
electronics = Category("Электроника")
electronics.add_product(apple_iphone)

# Просматриваем товары в категории
for product in electronics.products:
    print(product)
 ```
