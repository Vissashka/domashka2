# Каталог Продуктов и Категорий
## Описание
Данный проект реализует простой каталог товаров и категорий, предназначенный для демонстрации основных концепций объектно-ориентированного программирования (ООП) на примере организации торговли. Основная цель проекта — продемонстрировать возможности структурирования и управления данными с помощью классов, а также покрыть большую часть функциональности модульными тестами.

## Структура проекта
- src/: директория с исходниками программы.
- tests/: директория с модулем тестов для проверки правильности работы классов.
- data/products.json: файл с начальными данными для демонстрации загрузки из JSON.
## Особенности проекта
- Организация данных с помощью классов и иерархии объектов.
- Применение принципа инкапсуляции и приватизации атрибутов.
- Подсчет общей стоимости товаров на складе и количества продуктов в категории.
- Загрузка начальных данных из JSON файла.
- Интерактивное добавление товаров и изменение их характеристик.
## Установка зависимостей
Перед началом работы убедитесь, что у вас установлены все требуемые пакеты. Для этого рекомендуется использовать инструмент Poetry для управления зависимостями. Выполните установку зависимостей следующим образом:

poetry install
Запуск приложения
Для запуска основного сценария запустите следующий скрипт:


poetry run python src/main.py
## Прогоны тестов
### Для проверки качества кода выполните модульные тесты:


poetry run pytest tests/
## Детали реализации
### Классы и их функциональность
- Product: класс для хранения информации о товаре, включающей его название, описание, цену и количество.
- Category: класс для группировки товаров по категориям, хранит список товаров и позволяет рассчитывать общий остаток товаров.
## Методология проектирования
- Данные защищены с помощью приватных атрибутов и специальных методов-геттеров/сеттеров.
- Цена защищена от установки негативных значений и обеспечивается интерактивное подтверждение снижения цены.
- Используется метод загрузки данных из внешнего JSON файла для инициализации системы.
## Примеры использования
### Пример добавления товара и расчета его общей стоимости:
```Python
from src.models import Product, Category

# Создаем товар
bread = Product("Хлеб", "Белый хлеб", 50, 10)

# Создаем категорию
food = Category("Еда")
food.add_product(bread)

# Показываем статус категории
print(food)
```
